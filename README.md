# Samiul Islam — Data Science & Python Portfolio

Welcome! This repository is a collection of my data analysis, machine learning, and Python projects, completed as part of my coursework and independent practice. It's intended to give employers, professors, and collaborators a clear view of my technical skills and problem-solving approach.

## About Me

I'm a student working on Python, data analysis, and applied machine learning. Projects here range from exploratory data analysis to predictive modeling using real-world datasets.

## Projects

| Project | Description | Skills / Tools |
|---|---|---|
| [Beta Bank Churn Prediction](./Project%20-%20Beta_Bank_Churn_Prediction.ipynb) | Predicts whether bank customers will leave (churn), using classification models to help the business target retention efforts. | Python, pandas, scikit-learn, classification metrics |
| [Data Analysis with Pandas](./Project%20-%20Data%20Analysis%20with%20Pandas%20.ipynb) | Exploratory data analysis project demonstrating data cleaning, transformation, and visualization techniques with pandas. | Python, pandas, data cleaning, visualization |

| [Megaline Plan Recommendation Model](./Project%20-%20Megaline%20Plan%20Recommendation%20Mod...ipynb) | Builds a model to recommend the most suitable mobile plan to customers based on their usage behavior. | Python, scikit-learn, classification, model tuning |
| [Telecom Plan Revenue Analysis](./Project%20-%20Telecom%20Plan%20Revenue%20Analysis.ipynb) | Analyzes telecom customer usage and plan data to determine which plans generate more revenue. | Python, pandas, statistical analysis |
| [Video Game Sales Analysis](./Project%20-%20Video%20Game%20Sales%20Analysis.ipynb) | Explores global video game sales trends across platforms, genres, and regions to identify key success factors. | Python, pandas, data visualization |
